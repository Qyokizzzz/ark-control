# 主机助手重连与后台错误

## 离线和主动断开

普通网络离线时，正在运行的助手会自动重试。重新打开助手也会使用已保存的接入凭据，不需要新建主机。

在后台主动点击「断开主机」并完成停服后，旧凭据会被撤销。恢复时点击**原主机**上的「重新连接」，在原游戏电脑执行生成的命令。重连命令默认沿用原配置中的游戏目录和互通目录，不再把已有目录改成默认路径。原来指定 `--config` 的，继续带上相同配置路径。

如果离线时发出的断开请求一直没有完成，「重新连接」会取消这次待断开请求，并生成新接入码。

## 配置位置

默认配置固定保存在项目根目录下：

```text
.data/agent/config.json
```

无论通过 pnpm 还是直接运行助手，默认位置都相同。旧版 pnpm 可能把配置保存在 `apps/agent/.data/agent/config.json`；新版会读取并迁移这份旧配置，保留原文件、主机凭据和游戏目录。显式指定的 `--config` 或 `ARK_AGENT_CONFIG` 优先，不会改用其他主机的配置。

助手启动时会输出本次实际使用的管理地址、配置位置和游戏目录。连接成功后会明确显示「主机连接成功」。

## 内网 HTTP

首次接入可信内网的 HTTP 地址时，使用 `--allow-http`。后台生成的内网 HTTP 命令会自动带上该参数，接入后授权会保存到配置中，后续重启无需再次添加。已有旧版 HTTP 配置会保留原有选择。

`127.0.0.1` 指向运行助手的电脑自身。后台与游戏机器不同机时，命令中的后台地址必须能从游戏电脑访问。

## 「服务处理失败」

这是后台处理请求时的错误提示。旧版只返回通用文本，无法仅凭它确定具体原因。新版会在助手提示中附上失败接口和请求编号，并在**运行后台的电脑**保存详细错误：

```text
<DATA_DIR>/logs/api-errors.log
```

默认通常为后台项目根目录的 `.data/logs/api-errors.log`；修改过 `DATA_DIR` 时以该目录为准。后台终端也会输出错误代码、原因、调用位置和日志文件路径。日志不记录请求头或接入码，对常见凭据字段作脱敏处理。

本版还处理了两类可导致轮询反复失败的问题：

- 旧数据库已有 `resources` 表时，启动会自动补齐缺失的状态、到期字段及索引，保留原有 JSON 数据；升级不需要重新运行安装向导。
- 地图或好友联机密钥缺失、无法解密时，在对应主机显示明确告警，其他主机管理和心跳继续运行。启动等需要有效管理凭据的操作会被阻止，避免写入空密码；未运行地图仍可删除，随后回收存档并保留下载文件。

如提示密钥无法解密，检查是否保留原 `.env` 中的 `ENCRYPTION_KEY`。代码不会自动重建加密密钥或重置地图、机器人凭据。

## 更新

保留原 `.env`、`.data` 和游戏工作目录，更新后执行 `pnpm build`，重启后台与游戏电脑的主机助手。只刷新网页不会更新后台诊断和远程助手。

如果更新后仍失败，提供新版提示中的请求编号，以及后台 `api-errors.log` 中对应的那一条记录；原来的通用文本无法还原过去的具体异常。
