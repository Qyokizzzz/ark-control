# 地图与主机操作

地图管理列表和地图详情页共用操作入口，支持桌面和手机浏览器。

## 地图

- **启动 / 重启**：服务端已安装且未运行时显示「启动」，运行时显示「重启」。启动前仍检查主机资源；重启先保存退出旧进程，再创建新进程。
- **终止启动**可在地图列表或详情中提交。后台取消排队或执行中的启动，主机助手核对进程身份并结束进程，确认退出后恢复「未启动」。重启进入新进程加载阶段后也可终止。主机离线时保留请求，连接恢复后执行。
- **关闭**：可设置倒计时，结束后保存世界并正常退出。进程结束后清空 PID、启动时间、CPU 和内存数据，自动拉起不会再次启动主动关闭的地图。正常退出失败会如实显示错误，可在地图详情使用强制停止。
- **准备服务端 / 重新安装**：新地图默认优先复用本机空闲文件，为地图复制独立程序和模组，不复制旧存档、配置与日志；没有可用来源时下载。安装失败后列表和详情均提供重试按钮，保留已完成的文件，不必删除地图。执行中的任务会显示进度，期间阻止重复提交。
- **删除未运行地图**：确认没有运行进程、没有执行中任务时，可直接删除，无需主机在线，并取消该地图的自动启动意图。未安装、没有产生文件的新地图当场完成；已有文件的地图立即移出列表，后台保留收尾任务，助手连接后回收存档，将下载文件移入文件库。
- **删除运行中地图**：先正常保存停服，再回收存档、保留服务端文件，完成后移除地图记录。已开始保存或整理文件后不能取消；保存前的倒计时可在地图详情取消。

删除地图会移除其维护计划、部落订阅、部落识别记录及目标为此地图的好友联机入口和凭据。联机配置移除后，相关助手会结束对应组件。未发送的订阅消息停止后续推送；已经进入发送中的消息保留待核对状态。删除不会清理其他地图或共享互通目录。

存档从 `instances/<地图ID>/ShooterGame/Saved` 移入：

```text
<主机助手工作目录>/recycle/<地图ID>-<删除任务ID>/Saved
```

例如助手根目录为 `D:\ArkHost`，回收文件就在 `D:\ArkHost\recycle`。同级 `instance.json` 记录原目录、地图 ID、任务 ID 和回收时间。后台已有备份、历史任务和日志保留；备份仍可下载，地图已删除时不再允许直接恢复到该地图。回收存档是保留的数据，需要时可单独整理，不属于仍在运行的游戏资源。

服务端程序与公共地图资源位于 `<主机助手工作目录>/maps/<文件ID>`，多张地图可同时共用。删除地图会解除这张地图的引用并回收其运行数据，释放进程、内存和端口。共享文件保留在 `maps`，只有在文件库单独删除未关联、未预留且没有任务的文件时才释放这部分空间。详见 [服务端文件管理](SERVER-FILES.md)。

未运行地图的删除不要求助手在线。实际存档回收和文件保留仍由原机器的助手完成，主机页会显示待处理数量和失败原因，并提供重试入口；主机重新接入时会继续未完成的任务。存在待处理文件时暂不能删除主机，防止任务丢失。运行状态不确定或仍有任务执行中的地图，需要先核对状态，不能直接按未运行处理。

## 主机

- **断开主机**：取消尚未开始的任务，通知本机正在执行的任务停止或完成必要的收尾，再正常关闭全部地图、退出联机组件。停服产生的最后一批部落日志会先提交到后台队列。助手确认资源已释放后，后台撤销助手令牌及未使用的接入码，并显示「已断开」。地图配置和存档保留。
- **离线时断开**：保留「正在断开」请求，助手重新上线后完成清理。后台无法替离线电脑直接结束进程，因此不会提前显示资源已经释放。迟到的心跳也不会把断开请求改回在线。
- **关闭失败**：显示失败原因，保留连接以便继续处理地图，不把仍在运行的主机标成已断开。可以在地图详情强制停止后重试。
- **恢复连接**：点击原主机上的「重新连接」，在原机器执行生成的命令，沿用保存的游戏目录与自定义互通目录。若旧的断开请求卡在离线状态，此操作会取消待执行的断开请求。普通网络离线会由正在运行的助手自动重试，不需要新建主机。详见 [助手重连排错](AGENT-RECONNECT.md)。
- **删除主机**：先删除旗下地图并完成存档回收、断开连接，再删除主机记录和凭据。执行中的文件任务也要先结束。如果该主机还承担其他地图的好友联机入口，需要先处理这些入口。未接入、没有地图的主机可直接删除；离线空主机也可以移除。删除主机只移除后台的文件索引，机器上的文件库和回收存档继续保留；用原工作目录重新接入后会自动扫描。

手动关闭主机助手终端仍保留原行为：游戏进程继续运行，以便助手重启后接管。后台的「断开主机」是明确执行停服和资源清理的操作。

## 更新

保留 `.env`、`.data`、助手配置及游戏工作目录，更新源码后执行 `pnpm build`，重启管理后台与所有已接入的主机助手。新版后台根据每次轮询的文件管理能力标识，暂停向旧助手下发删除任务，页面会提示升级。仅更新网页不会自动升级远程助手；反向代理应保留 `X-Ark-Agent-Features` 请求头。不要降级到旧版助手执行删除任务。

## 验证范围

测试覆盖真实 Windows 子进程、RCON 端口释放、浏览器按钮、安装失败重试、存档回收、删除后端口重新分配、主机断开与凭据失效。游戏和 SteamCMD 使用本地替身；真实 ASE 保存、退出耗时及 Linux 进程行为仍需对应主机实测。
