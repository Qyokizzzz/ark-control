# 已确认需求

面向 ARK: Survival Evolved（ASE），浏览器操作，手机适配。游戏运行地点后定；通过主机助手接入 Windows 或 Linux，主机与地图数量可扩展。

- 地图实例一键安装、启动、正常停止、重启、强制停止；倒计时公告、存档、取消倒计时。
- 主机在线状态与资源指标；新地图创建和启动前预检，不把估算当作资源保证。
- 实例独立端口、地图、人数、PVE、倍率、模组顺序、互通组；配置重启生效。
- 玩家列表、公告、踢人、封禁、解封；日志和操作记录。
- 手动和定时备份、下载、恢复；恢复前保留当前存档。
- 服务端和模组更新；定时维护、崩溃后有限重启。
- 所有部落日志采集并保存；按地图实例、部落 ID 和目标 QQ 群精确分流。管理员配置订阅。
- 同名定义：去掉游戏时间及颜色标记后的正文完全相同。实体名、等级不同不合并。
- 合并窗口从第一条日志到达开始固定计时 30 秒，不因后续日志延后；到期发送，单条也显示数量 1。
- 消息格式必须是 `地图-部落名： 日志 (count)`。
- 默认 QQ 机器人与客户自带机器人共存，订阅明确选择，发送失败不隐式换机器人。
- QQ 凭据只存后端，密钥加密；群绑定属于具体机器人；测试发送与错误状态可查看。
- 平台限频、权限拒绝和不确定的网络结果必须如实记录；不承诺 QQ 端无条件即时送达。

## 2026-11-05 确认的版本、用户与商店范围

- 新地图选择公开 / preaquatica Steam 分支，跟随分支更新，不锁定 361 / 358 的具体小版本。同互通组保持同分支，文件库按分支复用。
- 浏览器用户管理按互通组筛选，以 SteamID 合并档案；独立服分别管理。保留地图详情的玩家列表，并增加历史名称、备注、在线采样时间和可采集的 IP、设备、VIP、金币。
- 管理员发币/扣币和限时 VIP，适配 ArkShop 与 Permissions，记录请求编号、原因、回执和异常状态。不同服使用独立经济库，同服多图共享对应插件数据库。
- SteamID 封禁下发全组；IP 只使用游戏实测且经核实的地址。设备封禁覆盖同意绑定且使用本项目联机客户端的用户，普通 Steam 直连仍允许。设备标识不能保证永久、不可伪造。
- 商店采用原生编辑器，支持商品、礼包、回收和 JSON 导入导出、草稿版本冲突检查、主机备份与逐图发布。
- 用户已确认不需要真实支付；首版不接支付、自动充值或玩家网页商城。
- 后台管理操作全部留痕，游戏消费以实际日志/桥接事件采集。不能用余额轮询承诺得到全部消费；可选桥接源码需要对应 ASE SDK 编译和实服验证。

部署和能力边界见 [版本、用户与 ArkShop 接入](PLAYER-SHOP.md)。
